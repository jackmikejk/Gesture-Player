# Security

Gesture Player is a static web page. It has no server, no accounts and no database outside your own browser, and it doesn't collect any data.

## Reporting a problem

If you find a security or privacy issue, please report it privately rather than in a public issue:

**Security tab → Report a vulnerability** on this repository.

Please include what you found, how to reproduce it, and which device and browser you used. You'll get a reply as soon as possible, and the fix will be published here.

## Supported version

Only the live version at https://jackmikejk.github.io/Gesture-Player/ is supported.
